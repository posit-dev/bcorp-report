# Data

Code and data files required for plots in the report.

The plots in `images/generate-plots.qmd` read four output CSVs, each
regenerated by its own script:

| File | Script | Source |
| --- | --- | --- |
| `python_package_downloads.csv` | `get_python_package_downloads.R` | BigQuery PyPI public dataset |
| `r_package_downloads.csv` | `get_r_package_downloads.R` | cranlogs |
| `rstudio_os_downloads.csv` | `get_rstudio_os_downloads.R` | committed `rstudio_downloads_legacy.csv` (before 2025-06) + warehouse `desktop-downloads/` + `server-downloads/` (from 2025-06) |
| `quarto_downloads.csv` | `get_quarto_downloads.R` | GitHub releases + committed `quarto_downloads_legacy.csv` (pre-2024 rstudio.com) |

`get_rstudio_os_downloads.R` reads the warehouse exports via
`read_warehouse_downloads.R`. The Python and R scripts resume incrementally
from the last recorded date in each CSV — re-running appends, it does not
rebuild. None of the get scripts read the raw `downloads.csv`; see below.

### The RStudio desktop/server sources

RStudio Desktop and RStudio Server (open source) downloads come from two eras,
split at 2025-06-01:

- **Before 2025-06-01** — `rstudio_downloads_legacy.csv`, a small committed
  daily summary (`date, type, downloads`) distilled from the internal
  `downloads.csv` feed. Quarto's pre-1.4 rstudio.com downloads are likewise
  frozen in `quarto_downloads_legacy.csv`.
- **From 2025-06-01** — per-month data-warehouse exports, gitignored:
  - Desktop → `data/desktop-downloads/`, produced by `helpers/desktop_downloads_job.R`
  - Server → `data/server-downloads/`, produced by `helpers/rstudio_server_downloads_job.R`

Both jobs run as Posit Workbench jobs. The server job filters to open-source
server at query time (Pro / Workbench editions excluded), so each export folder
is a single product and needs no re-classification.

#### The retired `downloads.csv`

`downloads.csv` (~755MB, gitignored) was the original internal metrics feed. It
froze in early 2026 and is too large for version control, so it is no longer on
the pipeline's primary path. `helpers/summarise_downloads_csv.R` distils it into
the two committed `*_legacy.csv` summaries above (via `read_rstudio_downloads.R`,
which holds the original filename-classification logic). Because the feed is
frozen, that helper should not need re-running; it is kept to document how
`downloads.csv` was processed and to rebuild the summaries if the raw file is
ever refreshed. The warehouse-vs-internal-metrics validation lives in
`helpers/rstudio-downloads.qmd`.

## Updating the data

1. **Refresh the RStudio download sources** (needed for the RStudio plot):
   - Run `helpers/desktop_downloads_job.R` and `helpers/rstudio_server_downloads_job.R`
     as Posit Workbench jobs to refresh the warehouse exports in
     `data/desktop-downloads/` and `data/server-downloads/`. Both are resumable
     — already-written months are skipped.
   - The pre-2025-06 history is frozen in the committed `rstudio_downloads_legacy.csv`
     and `quarto_downloads_legacy.csv`, so no refresh is needed. (They were built
     once from `downloads.csv` by `helpers/summarise_downloads_csv.R`; see the
     retired-`downloads.csv` note above.)

2. **Refresh Quarto releases from GitHub** (needs `gh` auth):

   ```bash
   ./helpers/github_quarto.sh   # regenerates releases.csv
   ```

3. **Run the scripts** (needs `bigrquery` auth + billing project
   `pypi-downloads-458318`, and `gh` auth for the r-lib repo list). Each writes
   one output CSV and can be run independently:

   ```bash
   Rscript get_python_package_downloads.R
   Rscript get_r_package_downloads.R
   Rscript get_rstudio_os_downloads.R
   Rscript get_quarto_downloads.R
   ```

   Tip: in `get_python_package_downloads.R`, uncomment the
   `bq_perform_query_dry_run()` line first to check the BigQuery bytes scanned
   before the real query runs.

4. **Re-render** `images/generate-plots.qmd`, then the report (`pbc-report.qmd`).

## Notes

- `downloads.csv` (~755MB) froze in early 2026 and is now retired (distilled into
  the committed `*_legacy.csv` summaries). The warehouse `desktop-downloads/` and
  `server-downloads/` exports carry desktop and server downloads forward from
  2025-06, so the RStudio plot keeps growing (~12% of cumulative added in the last
  12 months). Server is ~3% of the RStudio total.
- The legacy Quarto summary's contribution is negligible overall (~0.1% of total,
  all pre-2024-01-24) but is a meaningful share of the *early* Quarto versions;
  the rest of Quarto comes from GitHub releases.
