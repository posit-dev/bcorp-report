# Data

Code and data files required for plots in the report.

The plots in `images/generate-plots.qmd` read four output CSVs, each
regenerated by its own script:

| File | Script | Source |
| --- | --- | --- |
| `python_package_downloads.csv` | `get_python_package_downloads.R` | BigQuery PyPI public dataset |
| `r_package_downloads.csv` | `get_r_package_downloads.R` | cranlogs |
| `rstudio_os_downloads.csv` | `get_rstudio_os_downloads.R` | internal `downloads.csv` |
| `quarto_downloads.csv` | `get_quarto_downloads.R` | GitHub releases + pre-2024 internal `downloads.csv` |

The last two share `read_rstudio_downloads.R`, which reads and classifies the
internal `downloads.csv` feed. The Python and R scripts resume incrementally
from the last recorded date in each CSV — re-running appends, it does not
rebuild.

## Updating the data

1. **Refresh the internal `downloads.csv`** (needed for the RStudio plot).
   This is internal tracking data, gitignored, and must be fetched manually.
   Credentials live in `data/.env` (gitignored).

2. **Refresh Quarto releases from GitHub** (needs `gh` auth):

   ```bash
   ./helpers/github_quarto.sh   # regenerates releases.csv
   ```

3. **Run the scripts** (needs `bigrquery` auth + billing project
   `pypi-downloads-458318`, and `gh` auth for the r-lib repo list). Each writes
   one output CSV and can be run independently:

   ```bash
   Rscript get_python_package_downloads.R
   Rscript get_r_package_downloads.R
   Rscript get_rstudio_os_downloads.R
   Rscript get_quarto_downloads.R
   ```

   Tip: in `get_python_package_downloads.R`, uncomment the
   `bq_perform_query_dry_run()` line first to check the BigQuery bytes scanned
   before the real query runs.

4. **Re-render** `images/generate-plots.qmd`, then the report (`pbc-report.qmd`).

## Notes

- `downloads.csv` (~755MB) is the *only* source for the RStudio plot, which is
  still actively growing (~12% of cumulative added in the last 12 months).
- `downloads.csv`'s contribution to Quarto is negligible (~0.1% of total, all
  pre-2024-01-24); the rest of Quarto comes from GitHub releases.
